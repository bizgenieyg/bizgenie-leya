## Находки вне инструкций

1. **`gemini-3.8-flash` не укладывается в лимит ответа 1024 токена.** Лимит общий для рассуждений и текста; 33 вызова закончились `incomplete_max_tokens`, клиент получил заглушку «Я ассистент владельца. Уточню у владельца…». Это боевая конфигурация (`GeminiProvider`, `maxOutputTokens` 1024 для модели ответов), не настройка прогона. Перед переводом ответов на 3.8 нужен либо больший лимит, либо ограничение рассуждений — отдельное решение.
2. **Разбор знаний на `gemini-3.8-flash` падает.** Служебная модель по умолчанию (`GEMINI_TASK_MODEL` на сервере не задана) не разобрала `ira-facts.md` даже кусками по 600 символов (`incomplete_max_tokens` при лимите 8192). Тот же путь использует «Добавить знания» в кабинете — вероятно, на сервере он сейчас не работает для объёмных текстов. Проверить на живом тенанте.
3. **Заглушка при сбое модели безлична**: «Я ассистент владельца. Уточню у владельца…» — без имени владельца и повторяется на каждом ходе.
