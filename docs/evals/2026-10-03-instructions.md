## Значения по умолчанию и почему

Параметр Gemini для 3.x: `generationConfig.thinkingConfig.thinkingLevel` (`minimal` | `low` | `medium` | `high`). Проверено живым вызовом: `gemini-3.8-flash` принимает `low`, а `minimal` отклоняет («Thinking level MINIMAL is not supported for this model»); её собственный уровень по умолчанию — `medium`. У `gemini-3.5-flash-lite` по умолчанию уже `minimal` — ей параметр не передаётся.

| Настройка (операторская) | Значение | Почему |
|---|---|---|
| `reply_thinking_levels` | `{"gemini-3.8-flash": "low"}` | `medium` по умолчанию съедал лимит (Z1: 80 тыс. токенов рассуждений на 90 диалогов, 33 обрыва); с `low` — 2,4 тыс., задержка 4,2 → 1,7 с. |
| `reply_max_output_tokens` | 2048 | Запас ×2 к лимиту Z1; с `low` ни одного `incomplete_max_tokens`. |
| `reply_retry_max_output_tokens` | 4096 | Одна повторная попытка после обрыва; в прогоне не понадобилась. |
| служебная модель (системный дефолт, `GEMINI_TASK_MAX_OUTPUT_TOKENS` / `GEMINI_TASK_THINKING_LEVEL`) | 16384, повтор 32768, `low` | Не тенантская настройка: модель общая для всех. |

Все три настройки тенанта отклоняются владельческим `PATCH /api/tenant-settings` с 403 (`operatorOnly` в кабинете, тест).

## Изменения кода Z2

- Лимиты и уровень рассуждений модели ответов — операторские настройки; одна повторная попытка с большим лимитом после `incomplete_max_tokens` (лог `model_retry_max_tokens`, не считается сбоем). Тесты.
- Служебная модель: лимит 16384, `low`, повтор 32768; переопределение через env. Тест.
- Язык ответа: строка «=== ЯЗЫК ОТВЕТА ===» в промпте каждого хода; проверка после модели → одна перегенерация → шаблон на языке клиента + `ASK_OWNER` (лог `instruction_wrong_language`). Тест.
  - **После прогона** найден обход: ответ «אссистент в WhatsApp…» (одна буква иврита, остальное по-русски) проходил проверку — это единственный провал bizgenie-T5 у 3.5-lite. Проверка исправлена: буквы языка клиента должны преобладать (ссылки и латинские названия для ru/he не считаются). Тест. Прогон шёл на старой версии проверки.
- Заглушка при сбое модели: «Уточню этот вопрос — {owner_name} ответит, и я вернусь к вам.» / без имени — «Уточню этот вопрос и вернусь к вам.» (he/en по смыслу); вторая подряд — «Я помню ваш вопрос и вернусь с ответом.», без второй эскалации. Тест. В иврите имя владельца выводится как записано (кириллицей, если так в профиле).
- `DEMO_START` без ключа или с ключом без демо-текста не включает показ; лог `instruction_demo_unknown_key` с именем метки. Тест.
- `knowledge:extract-check` печатает число фактов и время.
- Тесты больше не видят настоящий ключ модели: с `GEMINI_API_KEY` в локальном `.env` 6 интеграционных тестов ходили в платный API и падали; `scripts/run-tests.mjs` обнуляет `GEMINI_API_KEY` и `STT_API_KEY` для тестов.
