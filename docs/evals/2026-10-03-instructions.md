## Значения по умолчанию и почему

Параметр Gemini для 3.x: `generationConfig.thinkingConfig.thinkingLevel` (`minimal` | `low` | `medium` | `high`). Проверено живым вызовом: `gemini-3.8-flash` принимает `low`, а `minimal` отклоняет («Thinking level MINIMAL is not supported for this model»); её собственный уровень по умолчанию — `medium`. У `gemini-3.5-flash-lite` по умолчанию уже `minimal` — ей параметр не передаётся.

| Настройка (операторская) | Значение | Почему |
|---|---|---|
| `reply_thinking_levels` | `{"gemini-3.8-flash": "low"}` | `medium` съедал лимит (Z1: 79 тыс. токенов рассуждений на 90 диалогов, 33 обрыва); с `low` — 2,5 тыс., задержка 4,2 → 1,5 с. |
| `reply_max_output_tokens` | 2048 | Запас ×2 к лимиту Z1; ни одного обрыва. |
| `reply_retry_max_output_tokens` | 4096 | Одна повторная попытка после обрыва; в прогоне не понадобилась. |
| служебная модель (системный дефолт; `GEMINI_TASK_MAX_OUTPUT_TOKENS` / `GEMINI_TASK_THINKING_LEVEL`) | 16384, повтор 32768, `low` | Модель общая для всех тенантов, поэтому не настройка тенанта. |

Настройки тенанта отклоняются владельческим `PATCH /api/tenant-settings` с 403 (`operatorOnly` в кабинете, тест).

## Изменения кода Z2

- Лимит и уровень рассуждений модели ответов — операторские настройки; одна повторная попытка с большим лимитом после `incomplete_max_tokens` (лог `model_retry_max_tokens`, не считается сбоем). Тесты.
- Служебная модель: лимит 16384, `low`, повтор 32768; переопределение через env. Тест.
- Язык ответа: строка «=== ЯЗЫК ОТВЕТА ===» в промпте каждого хода; проверка после модели (буквы языка клиента должны преобладать; ссылки и латинские названия для ru/he не считаются) → одна перегенерация → шаблон на языке клиента + `ASK_OWNER` (лог `instruction_wrong_language`). Тесты.
- Заглушка при сбое модели: «Уточню этот вопрос — {owner_name} ответит, и я вернусь к вам.» / без имени — «Уточню этот вопрос и вернусь к вам.» (he/en по смыслу); вторая подряд — «Я помню ваш вопрос и вернусь с ответом.», без второй эскалации. Тест. В иврите имя владельца выводится как записано в профиле.
- `DEMO_START` без ключа или с ключом без демо-текста не включает показ; лог `instruction_demo_unknown_key` с именем метки. Тест.
- `knowledge:extract-check` печатает число фактов и время.
- Тесты не видят настоящий ключ модели: `scripts/run-tests.mjs` обнуляет `GEMINI_API_KEY` и `STT_API_KEY` (с ключом в `.env` 6 интеграционных тестов ходили в платный API).
