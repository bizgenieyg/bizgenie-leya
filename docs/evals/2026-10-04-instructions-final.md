## Изменения Z3

1. **Числа ответа, который начинает показ.** Проверка чисел и пометки «для примера» идут по тексту демо, если в ответе есть допустимый `[[DEMO_START: key]]`; при `[[DEMO_END]]` — по фактам тенанта (раньше в ответе с `DEMO_END` числа сверялись с демо). Тест на PGlite: ход 2 B9 с ценой из демо проходит, с ценой не из демо — «Уточню»; цена тенанта после `DEMO_END` проходит.
2. **Найдено в ходе прогона: в ответ, начинающий показ, текст демо в промпт не попадал** (он добавлялся только при уже открытом показе). Модель не видела условный прайс и выдумывала цены и правила («70 ₪», «за 2 дня») → проверка чисел → «Уточню» (B9 0/3 в первом прогоне `d1cfa2f`). Теперь, если первый вариант ставит допустимый `DEMO_START`, перегенерация получает текст этого демо. Тест. B9: 0/3 → 3/3.
3. **`npm run instructions:publish`** — операторский скрипт через эндпоинты Z с `ADMIN_SECRET`: загрузка + активация, `--engine`, `--reply-model`, `--dry-run`, `--rollback`; тот же текст повторно новую версию не создаёт (список версий отдаёт `sha256` текста, сам текст не покидает сервер); текст прежней версии активирует её без новой загрузки. Проверено на PGlite с настоящими сервисами (публикация, повтор, новая версия, откат, демо). Порядок включения и откат — `docs/instructions-publish.md`.
