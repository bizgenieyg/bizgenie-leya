## Изменения кода Z4

1. **Реальные цены** — `src/config/model-prices.ts`: вход, выход, чтение и запись кэша; ступени по дате (Gemini 3.8 Flash с 01.01.2027) и по размеру промпта (Haiku 5.5 > 100K, OpenAI > 272K). Неизвестная модель → «цена не задана». Заглушечные цены удалены; `eval:dialogs` и отчёт переноса знаний — на той же таблице.
2. **Учёт каждой оплаченной попытки** (по ревью): после обрыва по лимиту расход первой попытки сохраняется (`usage.attempts`, сумма — в `usage`), в том числе в ошибке, если и повтор не удался; eval считает цену по каждой попытке и учитывает расход вызовов, завершившихся ошибкой. Тест воспроизводит случай ревью: две попытки по 1000 токенов → 2000 и $0.0002.
3. **`AnthropicProvider`** (Messages API) и **`OpenAIProvider`** (Responses API) — HTTP, без новых зависимостей, общий цикл (`http-model.ts`): тайм-ауты, один повтор на 429/5xx/сеть, один повтор с большим лимитом, те же коды сбоев, история как чат. Рассуждения выключены или минимальны: Haiku 5.5 — `disabled`; Sonnet 5.5 — `between_tools`; OpenAI — `none`, у `gpt-6.1-sol` — `low`. Claude: `cache_control` на системном промпте.
4. **Тайм-ауты вызова — операторские настройки** (по ревью): `reply_timeout_ms` 20000, `reply_attempt_timeout_ms` 9000, `reply_retry_delay_ms` 1500 — читаются в рантайме для любого провайдера ответов; системные дефолты — `MODEL_CALL_DEFAULTS`.
5. **Выбор провайдера по префиксу** `reply_model`: `gemini-` / `claude-` / `gpt-`; ключи `ANTHROPIC_API_KEY`, `OPENAI_API_KEY` (добавлены в `.env.example`); нет ключа → `MissingKeyProvider`.
6. **`reply_fallback_model`** (дефолт пусто): при `timeout` / `unavailable` / `network` / 5xx — одна попытка на запасной модели; лог `model_fallback`. Все новые настройки — операторские, владельческий `PATCH` отклоняет их с 403.
7. **Судья eval закреплён**: `EVAL_JUDGE_MODEL` = `gemini-3.8-flash`, флаг `--judge-model`.
