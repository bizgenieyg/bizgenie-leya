## Изменения кода Z4

1. **Реальные цены** — `src/config/model-prices.ts`: вход, выход, чтение и запись кэша; ступени по дате (Gemini 3.8 Flash с 01.01.2027) и по размеру промпта (Haiku 5.5 > 100K, OpenAI > 272K). Стоимость считается по каждому вызову. Неизвестная модель → «цена не задана». Заглушечные цены (`src/config/evals.ts`) удалены, `eval:dialogs` и отчёт переноса знаний переведены на ту же таблицу.
2. **`AnthropicProvider`** (Messages API) и **`OpenAIProvider`** (Responses API) — HTTP, без новых зависимостей, общий цикл с поведением Gemini (`http-model.ts`): тайм-ауты, один повтор на 429/5xx/сеть, один повтор с большим лимитом после `incomplete_max_tokens`, те же коды сбоев, история как чат.
   - Рассуждения выключены или минимальны: Claude Haiku 5.5 — `thinking: disabled`; Sonnet 5.5 — `between_tools` (`disabled` она отвергает); OpenAI — `reasoning.effort: none`, у `gpt-6.1-sol` — `low` (`none` она отвергает).
   - Claude: `cache_control` на системном промпте — 93–94 % входа из кэша.
3. **Выбор провайдера по префиксу** `reply_model`: `gemini-` / `claude-` / `gpt-`; ключи `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`; нет ключа → `MissingKeyProvider`.
4. **`reply_fallback_model`** (операторская, дефолт пусто): при `timeout` / `unavailable` / `network` / 5xx основной модели — одна попытка на запасной; лог `model_fallback` с причиной и обеими моделями; каждая сторона учитывается в расходе отдельно. Отклоняется владельческим `PATCH` с 403.
5. Тесты провайдеров, цен и запасной модели — без реальных ключей; раннер тестов обнуляет `ANTHROPIC_API_KEY` и `OPENAI_API_KEY`.
